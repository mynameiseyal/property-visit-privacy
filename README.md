# Property Visit — privacy policy

The single page Google Play's Data Safety form links to for
**Property Visit** (`com.evworks.propertyvisit`), served at
<https://mynameiseyal.github.io/property-visit-privacy/>.

The source of truth is `site/privacy.html` in the app's own (private) repository.
This repository exists only so the page can be public without the app's source
being public. If the policy changes there, copy it here as `index.html`.
